# P20 — Onboarding, settings, accessibility, performance tiers, sound

**Month:** 5 · **Brief:** §17.5 (refund design), §15 (performance), §19 Month 5 deliverables

## Why

The opening minutes decide refunds (brief §17.5). Settings + accessibility + performance options make
the slice Steam-grade.

## Scope

1. **Onboarding** that respects the refund timeline (brief §17.5): first strategic decision ≤3 min, first
   operation ≤8 min, first visible rival response ≤15 min, first loyalty consequence ≤30 min, first
   cinematic ≤60 min. **No 90-minute prologue.**
2. **Settings**: graphics/performance tiers, audio, gameplay.
3. **Rebinding** + **subtitle/text-size** support.
4. **Performance tiers** (brief §15): 60 fps @ 1080p High target; **500k/2M splat selection**;
   **mesh fallback** toggle; one-click 500k fallback; ensure city + splat never resident simultaneously.
5. **Sound mix**: ambient beds (imply population, brief §15), UI, music; cutscene-skip + dialogue
   acceleration (brief §17.5).
6. **First trailer capture** setup (real gameplay, no pre-rendered deception — brief §17.5).

## Verify

- Onboarding hits each refund-timeline beat in a fresh playthrough.
- Performance tiers measurably change FPS; the splat/mesh + 500k/2M toggles work; settings persist via save.
- Accessibility: rebinding + text-size + subtitles function.
