# P23 — Steam store assets + honest trailer + demo + license manifest

**Month:** 6 · **Brief:** §17 (monetization), §17.5 (refund), §2 (IP), §18 (commercial criteria)

## Why

Package the slice for Steam honestly. Expectation accuracy is the best refund mitigation (brief §17.5).

## Scope

1. **Steam store assets**: capsule art, screenshots (strong, cinematic, but real), store description that
   **accurately matches the slice** (brief §18).
2. **Honest gameplay trailer**: shows **real strategic gameplay** in the first store trailer, NOT a
   misleading pre-rendered cut (brief §17.5). Never hide that first-person sections are constrained
   narrative sequences.
3. **Public demo config**: a 30–45 minute public demo (brief §17.5).
4. **Monetization setup** (brief §17): premium $29.99, no microtransactions/premium currency/always-online,
   no base content chopped for a season pass. Optional soundtrack/art-book hooks only. ≤10% launch discount.
5. **License + provenance manifest** (`docs/provenance-manifest.md`): record EVERY generated + purchased
   asset's license (Marble/Meshy/Tripo/local), per the brief's "record all asset licenses" criterion.
6. **IP review** (brief §2): title trademark search + character/title similarity review completed and
   documented BEFORE any public announcement.

## Verify

- Store page text matches actual slice content; trailer is real gameplay; demo is the stated length.
- Provenance manifest covers every shipped asset; IP/similarity review documented.
